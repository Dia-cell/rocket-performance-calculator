# Rocket Performance Calculator
A python based rocket perfomance analysis tool that calculates key propulsion and mass-performance parameters using the ideal rocket equation.

# Features
- Exhaust velocity calculation
- Specific impulse calculation
- Mass ratio calculation
- Delta-v Calculation
- Thrust to weight ratio
- Burn time
- Propellant mass freaction
- Input Validation
- Physics based performance assesment
- Delta-v sensitivity analysis
- Exhaust velocity sensitivity analysis
- Rocket configuration comparison
- Data export to CSV
- Performance graphs
- Delta-v validation

# Engineering Equations
- Exhaust velocity: ve = F / mdot
- Specific impulse: Isp = ve / g0
- Mass ratio: MR = m0 / mf
- Delta-v: = ve x ln(m0 / mf) 
- Thrust to weight ratio: T/W = F / (m0 * g0)
- Burn time: tb = mp / mdot
- Propellant mass fraction: PMF = mp / m0
